Mountain Torq IT Helpdesk for Android 8 and newer.

Download the APK on your Android device and open it. Android may ask you to allow installation from your browser. Sign in using your existing helpdesk account; the same role permissions apply.

The Android app provides a dedicated app window for the hosted mobile helpdesk, with photo selection, navigation, retry, and supported PDF/Excel/photo downloads. It requires internet access. The Browser button opens the same portal in your browser (you may need to sign in there separately).

This release does not include background push notifications, Windows device collection, or scheduled UPS popup windows on mobile. Tickets and website interface changes update from the hosted site.

Release APKs must use the same private signing key for future in-place updates. Windows desktop releases and downloads remain separate.
