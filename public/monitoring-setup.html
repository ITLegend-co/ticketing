Device monitoring setup

Monitoring is separate from ticketing. Only active IT Admin, IT Technician and Management accounts can view device readings. Only IT Admin can enrol or revoke devices. No monitoring emails are sent.

1. Enable Firebase access — once

  1. Open Firebase Console → ticketing-a8461 → Realtime Database → Rules.
  2. Save a copy of the current live rules first.
  3. Download the monitoring rules additions. Add the three top-level entries (monitoringDevices, monitoringCurrent, monitoringHistory) inside your existing rules object. Keep the existing users and tickets sections unchanged.
  4. Click Publish. If your live rules match this project's current ticket rules, the complete combined rules file is also provided.

The website cannot publish Firebase rules itself. Do not change database access to public. The existing Email/Password authentication provider is used for separate device accounts.

Updating an existing monitored computer

For public IP and MAC address reporting, publish the updated monitoring rules, install the newest Windows app, then run Set up device monitoring again with that computer’s enrollment file. Updating the app alone does not replace the collector already installed in ProgramData. If the file was deleted, revoke the old enrollment and create a new one for that computer.

2. Install on one pilot computer

  1. Download the current Windows installer from the helpdesk website. Quit the old app from the tray, then install the update.
  2. Sign in as IT Admin → Device Monitoring → Enrol a computer. Enter a label, location and department.
  3. Download the setup file. It contains credentials for this one device; keep it private.
  4. On that computer, right-click the helpdesk system-tray icon → Set up device monitoring. Approve Windows administrator elevation and select the setup file.
  5. Confirm installation. Delete the downloaded file once setup succeeds. Do not reuse it on another PC.
  6. Check the dashboard after 1–2 minutes. Confirm its name, location, hardware and readings before rolling out further.

What runs on the computer?

The Windows scheduled task Mountain Torq Device Monitoring runs as SYSTEM at startup and every minute. It remains active when the helpdesk is closed or users sign out. It does not wake a sleeping PC. Offline means no recent report; it cannot distinguish power-off from a lost connection.

Settings, the collector and encrypted device credentials are stored in C:\ProgramData\MountainTorqMonitoring, accessible only to Windows administrators and SYSTEM. The background task uses a device-specific Firebase refresh token, never an administrator credential.

Current readings update every minute. Inventory refreshes every six hours. Five-minute CPU/RAM history keeps up to 288 slots (24 hours); stale samples are excluded from the chart. Historical records stop updating when offline. There is no replay of offline readings.

Hourly network samples are optional and use about 1 MB download and 250 KB upload per test plus overhead. They are approximate transfer measurements, not a full speed test. Hardware temperatures, SMART and battery data depend on driver support. Antivirus information is Windows' reported product/state, not a guarantee that protection is healthy. Restart pending is checked, but this version does not scan for or install Windows updates.

Network addresses show Local IP Address and MAC Address per IP-enabled adapter. They refresh with each report. Public IP Address is checked every 15 minutes using ipify; the request sends no ticket content or device credentials. A failed lookup shows Unavailable. A shared connection or VPN may report the same public IP for multiple computers. MAC addresses may be virtual or randomized. Old collectors keep reporting their existing local IP until monitoring setup is run again.

Disable or remove monitoring

IT Admin can select a device and revoke its access to stop accepted uploads. On the PC, use the tray's Remove device monitoring action with Windows administrator permission to remove the scheduled task and local configuration. Removing the helpdesk app alone does not remove the separately installed task. Device history remains in Firebase for administrators to review.

If reports do not arrive

Check that the device is active and the rules were published, and that the PC has internet access. A Windows administrator can inspect C:\ProgramData\MountainTorqMonitoring\status.txt and the task's last result. Hardware collection and desktop launch are tested on a Windows build runner; the first company-PC pilot must verify actual Firebase upload and hardware compatibility.
